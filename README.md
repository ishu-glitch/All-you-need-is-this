## ⚡ Core & Productivity Tools
* [VS Code](https://github.com/microsoft/vscode) - Visual Studio Code is a code editor redefined and optimized for modern web apps.
* [Git](https://github.com/git/git) - Free and open source distributed version control system.

## 🌐 Frontend & UI Engineering
* [React](https://github.com/facebook/react) - The library for web and native user interfaces.
* [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss) - A utility-first CSS framework for rapid UI development.

## ⚙️ Backend, APIs & Databases
* [Node.js](https://github.com/nodejs/node) - JavaScript runtime built on Chrome's V8 engine.
* [FastAPI](https://github.com/tiangolo/fastapi) - High performance, easy to learn Python web framework.

## 🧠 Artificial Intelligence & ML
* [Ollama](https://github.com/ollama/ollama) - Get up and running with Llama 3, Mistral, and other LLMs locally.
* [Transformers](https://github.com/huggingface/transformers) - State-of-the-art Machine Learning for PyTorch and TensorFlow.
